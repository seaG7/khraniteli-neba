Кооперативный survival от первого лица

Двое игроков на японской локации собирают орудие из найденных деталей, заряжают его и уничтожают Источник. Параллельно отбиваются от процедурных пауков: те лезут волнами и могут обездвижить игрока.

Механика · орудие

Перенос и сборка орудия

  • Физический перенос. Подними деталь, неси её, можно бросить — настоящая физика.
  • Сборка в сокеты. Детали вставляются по порядку — орудие собирается из частей.
  • Одно орудие на двоих. Общий проект — роли делятся по ходу.
  • Пауки отрывают модули. Оторванное нужно подбирать и вставлять обратно.
Механика · враги

Враги — процедурные пауки

  • Процедурная анимация. Ноги просчитываются отдельно — походка живая, не зацикленная.
  • Движение по поверхностям. Ползут по стенам и зданиям, без NavMesh.
  • Атака. Прыжок, присасывание к игроку, обездвиживание.
  • Захват тела. Ноги цепляются за кости персонажа и следуют за ними.
Цель пауков — орудие; игрок на пути попадает под атаку.

Сеть · реализация

Как это сделано на FishNet

Клиент → Сервер
валидирует → SyncVar / ObserversRpc → SignalBus → UI
у всех клиентов
SyncVar — состояние Источника, заряд орудия, жизнь игрока, исход раунда.
ServerRpc — выстрел, захват и бросок, удар, выпивка.
ObserversRpc — гарпун, сборка орудия, эффекты, смена состояния.
Broadcast — лобби без NetworkObject: ник, готовность, старт.
NetworkTransform — движение владельца, остальные интерполируют.
Инъекция — InjectableNetworkBehaviour (Zenject-контейнер сцены).
// клиент просит → сервер валидирует → рассылает всем
[ServerRpc]
void ServerFire(Vector3 dir) { /* проверка + урон */ }

[ObserversRpc]
void RpcLaunchHarpoon(Vector3 from, Vector3 to);

// состояние реплицируется само + событие у каждого
[SyncVar(OnChange = nameof(OnState))]
public SourceState State;

// лобби без NetworkObject — FishNet Broadcast
broadcast.Broadcast(new LobbyStateBroadcast(…));
